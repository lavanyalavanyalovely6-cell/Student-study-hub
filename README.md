# Student Study Hub – SITAMS CSE (AI & ML) R23

This build uses the official SITAMS CSE (AI & ML) R23 course-material structure as the curriculum basis.

Official sources:
- https://sitams.ac.in/cseaiml/course-material/
- https://sitams.ac.in/cseaiml/regulation-and-syllabus/

Current implementation stage:
1. Official R23 semester and subject structure integrated.
2. Materials page is semester-aware and distinguishes theory/lab courses.
3. Quiz page lists theory subjects and preserves the 30-question verification rule.
4. Unit Notes page links to official SITAMS resources and does not present unverified placeholder PDFs as official material.
5. Next content stage is exact unit-topic extraction, source mapping, original revision notes, PDF generation, and verified 30+ question banks.

Important: A question bank is not marked verified until its questions have been checked against the applicable SITAMS R23 syllabus/material.

## SITAMS R23 source update
The academic database now includes verified I Year Semester II subjects from an official SITAMS R23 examination schedule, alongside the program-specific II-VII semester course-material listings. I Year Semester I and VIII Semester remain explicitly pending where the current program-specific public course-material mapping does not provide enough detail.


## V8 content stage
Exact syllabus unit blocks are now source-mapped from the uploaded `R23-CSE-AIML.pdf` for the core theory courses where the document exposes the unit structure. The app does not label unsourced placeholders as verified notes or questions.
